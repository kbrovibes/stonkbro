# v0.24.2 — Bloodbath: falling-knife signal + market benchmark

## Falling-knife signal

`buildTicker` now derives a daily %-change series from the bars it already fetches
(appending today's live quote change when Tradier's last bar isn't today) and computes:

- `redStreak` — consecutive down days ending today
- `worstDayToday` — today is the single worst day of the 4-week window
- `knife` — today red AND (streak ≥ 3 OR worst day today)

UI: 🔪 "falling" chip on the card header; streak/worst-day detail in the expanded view.
AI: ticker blocks include a "KNIFE STILL FALLING" line and the prompt forbids BUY_DIP
on a live knife absent a compelling company-specific reason (default WAIT/NIBBLE +
say what would confirm a floor).

## Market benchmark row

- `scanBloodbath` always scans SPY + QQQ (`BENCHMARK_SYMBOLS`) alongside the universe
  and returns them as `benchmarks` (excluded from watchlist/market lists).
- Stored per scan (`bloodbath_scans.benchmarks` jsonb, migration
  `20260728_bloodbath_benchmarks.sql`, applied to prod; old rows read as `[]`).
- Page: benchmark strip above the summary tiles with drawdown + today move per index
  and a computed one-liner (deep/broad selloff → mild dip → idiosyncratic), plus a
  "be patient" suffix when an index itself is knifing.
- AI: benchmark context line in the prompt ("a name down 30% while SPY is down 5%
  has 25 points of company-specific damage").
- `POST /api/bloodbath/verdict` accepts an optional `benchmarks` array; the page
  passes it on live-scan fallback.

## Layout rework (same release)

- Stacked full-width cards → compact tile grid (`grid-cols-2`, `sm:grid-cols-3`);
  tile shows symbol, drawdown, today %, 🔪, verdict chip.
- Tap a tile → bottom-sheet (`fixed inset-0` + backdrop) with summary stat boxes,
  peak/streak line, AI reasons, entry idea, confidence, ticker link.
- Sticky quick-nav bar (`sticky top-16`) under the summary tiles: jump buttons to
  the Watchlist / Market sections (`scrollIntoView`, `scroll-mt-28` anchors) and an
  ⓘ Verdicts toggle that expands a legend defining BUY_DIP / NIBBLE / WAIT / AVOID
  and the 🔪 knife flag.
