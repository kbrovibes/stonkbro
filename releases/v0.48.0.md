# v0.48.0 — Two new Paper Lab bots: Updraft and Afterburner

## What was requested
Add a bot that trades LEAPS and calls heavily, and a bot that plays earnings aggressively with real options structures (e.g. MU reporting this week), where every strategy, and the reasoning behind it, is visible.

## What shipped

### Updraft (`leaps-trader`) — `src/lib/paper/strategies/leaps.ts`
Long calls only, as opposed to Longview (PMCC), which writes calls against its LEAPS.
- Core: up to 4 LEAPS, ~0.75Δ, 365–550 DTE, ≤$12K each. Closed when delta falls under 0.55.
- Swing: up to 4 calls, ~0.55Δ, 30–60 DTE, only on names above the 50-day SMA with a 20-day return over 8%. Closed at +60%, −40%, or 10 DTE.
- One position per name across both books.

### Afterburner (`earnings-swing`) — `src/lib/paper/strategies/earnings.ts`
- Each session scans its universe (mega-caps, growth basket, MU, CRWD, SMCI, DIS) for reports within 5 calendar days.
- Structure from trend: above the 50-day with 20d return > +5% → long call (~0.45Δ); below with < −5% → long put; otherwise long strangle (~0.30Δ each side).
- Expiry: first cycle 1–10 days after the report. Size: 8% of equity per leg, ≤$15K.
- Exit: +75% / −50% per leg, else forced close 2 trading days after the report. Open plays are tracked in `account.state.earningsPlays` so a bet isn't re-entered across cron ticks.
- Each entry's trade reason records the thesis, e.g.
  `MU reports 2026-09-30 (3d) · long call: 20d +6.6%, +7.6% vs the 50-day · market prices ±5.9% through 2026-10-02 · 0.52Δ call, breakeven 123.63 (+3.0% from spot) · $7,637 at risk, 7.6% of equity`

### Engine plumbing
- `src/lib/market/earnings.ts`: `earningsDateSync(symbol, date)`, a synchronous lookup from the existing reporting-pattern table.
- `src/lib/paper/market.ts`: `loadEarnings()` stores the live calendar on `MarketData.earnings`; `runner.ts` calls it for earnings profiles.
- `StrategyContext.earnings(symbol)`: returns the live calendar when it's loaded, otherwise the pattern table (backfill).
- Both new ids added to `INDICATOR_PROFILES` so their SMA/return reads have history.
- `identity.ts`: faces, roles and creeds for both bots.

## Verification
`tsc` and `next build` are clean. An offline dry run on synthetic chains covered: Updraft buying 4 core LEAPS; Afterburner opening a bullish MU call 3 days before the print and taking profit after it; and the strangle path on a flat trend. The live calendar currently returns MU on 2026-09-30.
