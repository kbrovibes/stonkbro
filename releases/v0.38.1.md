# v0.38.1 — HOOD is the default theme style

`DEFAULT_THEME_STYLE` flipped from `classic` to `hood`:

- Devices with no stored choice (or a cleared localStorage) now render HOOD.
- An explicit Classic selection (`stonkbro-theme-style = "classic"`) still
  wins — the setting remains per-device.
- The pre-paint script now sets `data-theme-style="hood"` unless the stored
  value is exactly `"classic"`, so defaulted devices paint HOOD from the very
  first frame.
- `useThemeStyle()`'s server snapshot flipped to `"hood"` to match what the
  majority of clients will hydrate into.
- Settings → Appearance lists HOOD first, marked as the default.
