# v0.26.1 — Nav consolidation: Plays absorbs Options, Learn goes top-level

## Problem

Six bottom-nav slots (Home, Plays, Options, Portfolio, Hindsight, More) with
two of them — Plays (/today) and Options (/csp-hunter) — serving near-identical
"what should I trade today" purposes, while Learn (now 100+ lessons and 80 case
studies) was buried in the More menu. Hindsight had both a nav tab and an
in-page link on Portfolio.

## What shipped

- **`/plays`** — one page, five sub-tabs:
  - **Market** — explosive movers + options flow (the old /today, minus its
    long-dead Premium Plays block)
  - **CSPs / Calls / LEAPS / Weekly** — the old CSP Hunter scanner, unchanged
  - Split into `MarketTab.tsx` / `ScannerTabs.tsx` with a thin shell; both
    stay mounted across tab switches (CSS visibility), so a running scan or
    loaded market data survives tab hopping. OfflineGate wraps the page.
- **Bottom nav**: Home · Plays · Learn · Portfolio · More. Learn gets a
  graduation-cap icon. Hindsight tab removed — the Portfolio header's
  "⏰ Hindsight" chip is now its home (it was already there). Guest nav:
  Plays · Research.
- **Routing**: `/today` and `/csp-hunter` are server redirects to `/plays`
  (old push-notification/email URLs keep working); `/plays` added to the
  guest allowlist in middleware; landing + login entry links updated.
- **More menu**: Learn + CSP Hunter entries removed (now bottom-nav
  reachable); everything else unchanged.

## Verification

- `tsc --noEmit` clean; production build passes (56 routes).
