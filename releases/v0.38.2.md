# v0.38.2 — Biggest Movers for empty homes + second account allow-listed

## Biggest Movers fallback (`home/page.tsx`)

When a signed-in user (or guest) has zero watchlists, the home page now
fetches quotes for the `SCAN_UNIVERSE` (~110 liquid names, one batched
Tradier call, concurrent with the other home fetches) and renders:

- **Today's Winners** — top 5 by day change
- **Today's Losers** — bottom 5 (biggest loss first)

Both groups reuse `WatchlistWidget` (new `readOnly` prop hides + Add / Edit),
so the section is pixel-identical to the watchlist layout: symbol, price, day
change, sparkline, group average return. The header carries a
"Create Watchlist" link; the old empty-state card remains as the fallback if
the quote fetch fails.

## Brokerage link access

`chinnunchunni@gmail.com` added to `PORTFOLIO_ALLOWED_EMAILS`. This exposes
Settings → Brokerage, Portfolio, Hindsight, taxes, and briefings to that
account. **Caveat (unchanged architecture):** SnapTrade is a single app-wide
identity (`SNAPTRADE_USER_ID`/`SECRET`), so every allow-listed email sees the
same real portfolio — true per-user brokerage linking remains future work.
