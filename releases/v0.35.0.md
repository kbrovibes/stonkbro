# v0.35.0 — Daily Audio Briefing

## Problem

Pre-market prep meant reading several pages (portfolio, bloodbath, earnings, news) before 6:30am. There was no single, fast, portfolio-curated summary — and nothing consumable hands-free.

## Implementation

- **Content pipeline** (`/api/cron/briefing`, weekdays 13:00 UTC = 6am PT): gathers open option chains + holdings from the SnapTrade chains cache, live quotes for portfolio symbols plus SPY/QQQ, fresh Yahoo news headlines per portfolio symbol, upcoming earnings (≤7 days), and last-24h market-monitor alerts. The AI provider (Claude/Gemini with rate-limit fallback) writes a ~2–3 minute spoken script: market pulse, biggest portfolio moves and why, news/earnings that matter today, concrete trade suggestions (close / roll / open / watch with reasons), signoff. No account-level dollar amounts by design (privacy).
- **TTS**: Microsoft Edge neural voice `en-US-AndrewNeural` at +10% rate via the free Read Aloud endpoint (no API key). Output is 24 kHz 48 kbps mono MP3 — ~1 MB for 3 minutes — uploaded to a private Supabase Storage bucket `briefings` and streamed through auth-gated `GET /api/briefing/audio/[id]`.
- **Storage**: new `daily_briefings` table (migration `20260816150000`): transcript, title/summary, structured highlights + suggested-actions JSON, mood, art seed, audio metadata. History kept; the last 7 days surface in the player.
- **Home card** (portfolio-access users): generated cover-art thumbnail, today's title + teaser, tap → `/briefing`.
- **Player** (`/briefing`): Spotify-style — deterministic generative SVG cover art (seeded, mood-tinted palette), play/pause, ±15s skip, seek, 1x/1.25x/1.5x speed, transcript, highlights strip, action list, previous-briefings history. Played/downloaded audio is cached via Cache Storage (Download button; works in airplane mode). Regenerate button forces a fresh episode.
- **Jobs**: both cron and manual runs register in the Actions Center (kind `audio-briefing`) and are cancellable between phases.
- APIs: `GET /api/briefing` (list), `POST /api/briefing` (force regenerate), `GET /api/briefing/audio/[id]`, `GET /api/cron/briefing`.

## Notes

- Cost design: TTS is free, audio is low-bitrate mono, one AI call per day, news comes from the free Yahoo endpoint — the marginal daily cost is a single text-generation call.
