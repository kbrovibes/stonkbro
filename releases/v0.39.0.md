# v0.39.0 — Trading Desk + Decision Journal + Debate Verdict

Ported from the TradingAgents research framework, re-architected so the server
computes evidence deterministically and the LLM only writes narrative — **2 LLM
calls per full scan, not per ticker**. Five new subsystems compose into the
`/desk` Trading Desk page: a Decision Journal journaling every recommendation
ever surfaced, a Bull/Bear Debate evidence ledger with ratings, a Risk Desk
portfolio gate, Market Regime analysis, and News Sentiment. All additive; CSP
Hunter and /plays pages untouched.

## Decision Journal + Reflection

Every recommendation surfaced (scanner, research, consensus, etc.) is now
journaled. A cron job grades each recommendation against what actually
happened, computing realized return, max drawdown, whether it hit a stop,
days held, etc.

- **New tables** (`20260903190000_trade_decisions.sql` +
  `20260903210000_trade_decisions_period_return.sql`): decision entries
  linking to the scan/analysis that produced them, plus realized outcomes
- **Backfill**: 9,065 decisions from 255 historical scans (May–Aug 2026)
- **Zero LLM calls** — pure computation
- **API** `/api/journal` (authenticated) lists decisions with return/outcome
  summaries; tap any card to see the analysis that triggered it and the
  realized P&L
- **Cron** `/api/cron/reflect` runs the grading job; tracked in Actions Center

## Bull/Bear Debate Verdict

A deterministic evidence ledger runs on every ticker in the scan universe,
producing quantified bull vs. bear points (technicals, breadth, sentiment,
correlated-asset signals, etc.). The ledger emits a **rating**: BUY /
OVERWEIGHT / HOLD / UNDERWEIGHT / SELL. Returns **HOLD** when evidence is
balanced or thin, rather than manufacturing a directional bias.

- **One batched LLM call** narrates top candidates' theses (why BUY, why SELL)
  so you understand the evidence, not just the number
- **Degrades gracefully** if AI is unavailable; the ledger-only rating still
  exports as JSON
- Used by the scanner to curate recommendations (BUY/OVERWEIGHT are
  candidates; UNDERWEIGHT/SELL are excluded)

## Risk Desk

Portfolio risk gate runs deterministically before recommendations surface. Per
candidate, it emits one of:

- **APPROVE** — no conflicts, full size
- **SIZE_DOWN(n)** — reduce size by n units to meet concentration limits
- **REJECT** — no room in the portfolio

Checks:

- **Assignment capacity** — total collateral available to assign wheels
- **Single-name concentration** — a maximum per ticker
- **Sector concentration** — grouped by GICS sector
- **Correlated-cluster baskets** — when three or more names move together,
  tighten the group limit
- **Earnings clustering** — don't stack earnings-adjacent plays
- **Liquidity** — bid-ask spread must be ≤ 0.5% of mark

## Market Regime

Quantifies market mood from SPY trend, VIX, breadth, and risk appetite.
Returns one of:

- **RISK_ON** — bullish regime, loosen delta/DTE bands
- **NEUTRAL** — balanced
- **RISK_OFF** — bearish, tighten bands
- **VOLATILE** — high-uncertainty regime

The scanner uses these thresholds to auto-tighten delta and DTE requirements
when appropriate (e.g., wider deltas when bullish, narrower when risk-off).

API `/api/regime` exposes the current regime + component scores (SPY RSI, VIX,
$TICK breadth, etc.).

## News Sentiment

Deterministic keyword classifier (bullish vs. bearish terms) runs on each
headline, scoring tickers with a composite sentiment range. One batched LLM
call (all tickers at once) refines any headlines that don't parse clearly.
Falls back to keywords-only if AI is unavailable.

Exported alongside other signals in the Debate Verdict ledger.

## /desk Page & API

New page ("Trading Desk") lives in the Options group of the nav (alongside
Scanner, CSPs, Covered Calls, PMCCs, etc.); exposes:

- **Decision Journal** — tap to see past recommendations and realized outcome
- **Today's Verdict** — BUY / OVERWEIGHT / HOLD candidates ranked by
  conviction, with the AI-narrated thesis for each
- **Risk Gate** — per-candidate approval/sizing, showing which ones cleared the
  portfolio risk check
- **Market Regime** — current mood + component scores; VIX, breadth, SPY trend

API `/api/desk` serves all four components in one response; used by the page
and piped into the morning briefing.

## Provider Fallback Fixes

Two bugs in `src/lib/ai/provider.ts` affected every AI feature:

1. **Billing/credit-exhaustion errors never triggered fallback** — only rate
   limits did. Now when Anthropic credits run out, the app gracefully downgrades
   to the configured Gemini instead of failing silently.
2. **Gemini 2.5 thinking tokens expanded unpredictably** — they spend from
   `maxOutputTokens` and Gemini expands to fill whatever is given (observed:
   2396/2500, then 7678/8000), truncating every JSON response. Now
   `thinkingConfig.thinkingBudget = 0` is set explicitly to disable thinking on
   this model.
