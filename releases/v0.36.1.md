# v0.36.1 — Briefing playlist semantics

## Changes

- **Append, don't replace**: `generateDailyBriefing` no longer deletes the previous completed briefing for the same date — `deleteOlderBriefingsForDate` became `deleteUnfinishedBriefingsForDate` (clears only failed/stuck rows). `getLatestBriefings` returns every completed generation newest-first (plus the newest row while it's still running, so "preparing" states surface), capped at 30 entries; the 7-day retention sweep remains the real bound.
- **Hour stamps**: player header and playlist rows show `fmtHour(created_at)` — generation time rounded to the nearest hour — next to the date, distinguishing multiple same-day episodes.
