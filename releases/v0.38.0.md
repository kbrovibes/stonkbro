# v0.38.0 — Premium home page + alert folder

## Feature cards (`home/page.tsx`)

The Bloodbath / Portfolio / Hindsight row previously used emoji glyphs on
red/sky/amber tinted slabs — three different surface colors fighting the HOOD
canvas. Rebuilt as monochrome cards:

- `hood-card` surface (white / `surface-elevated`) with hairline border
- Heroicons thin-stroke line icon (trending-down, chart-bar, clock) inside a
  muted `w-9` circle — the icon glyph is the only colored pixel
  (loss-red / gain-green / amber)
- Descriptions dropped; the cards now read as buttons

## Section headings

One shared treatment across the page, Robinhood-style:

- "Upcoming Catalysts" and "Watchlists": `text-[17px] font-bold
  tracking-[-0.01em]`, action link (`Full Calendar`, `Manage`) as
  `text-xs font-semibold` accent green, baseline-aligned
- Watchlist group names (GPUs, Quantum…): `text-sm font-bold` with the group
  return at 11px — the hierarchy is now heading (17) → group (14) → card copy

## Catalyst pills (`UpcomingCatalysts.tsx`)

Red/amber tinted chips replaced with neutral pills (`surface-muted` +
hairline, rounded-full). The urgency signal moved into the day-count text
color: rose for this-week, subtle gray otherwise.

## Alert banner folder (`AlertBanner.tsx`)

30 stacked alerts made the old full-width red slab unusable. New design:

- **Collapsed (folder)**: white/dark card with a severity icon bubble
  (bell + count badge), the top alert's title (critical alerts sort first),
  and a summary line — `30 alerts · 5 critical · SOFI, NVDA, CRWV +6`.
  **Clear all** pill and expand chevron sit in the header.
- **Expanded**: a `max-h-80` scrollable tray; each row has a severity dot,
  title, 2-line-clamped body, suggested action, and Open / Dismiss.
- Privacy lock still hides titles, bodies, and the symbol summary.

## Play glyph

`HomeBriefingCard` still had the old right-shifted play path plus a
`translate-x-px` nudge — replaced with the same stroke-rounded,
optically-centered triangle the briefing player got in v0.37.2.
