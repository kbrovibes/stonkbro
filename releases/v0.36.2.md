# v0.36.2 — Theme Style per-device hint

## Context

A "HOOD isn't changing anything" report. Validation on prod showed all four combinations render correctly (Classic/HOOD × light/dark; canvases #FAFAF9 / #000 / #FFF / #0E1014, hood CSS rules present, pre-paint attribute applied). The likely confusion: the style is persisted in localStorage, so it only applies to the device it was toggled on — and nothing in the UI said so.

## Change

- `THEME_STYLES` hints in `src/lib/theme-style.ts` now end with "Set per device." (shown as the Theme Style row subtitle in Settings → Appearance).
