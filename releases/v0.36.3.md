# v0.36.3 — Face ID lock kill switch (temporarily off)

## Context

The v0.33.0 Face ID app lock is misbehaving and needs debugging. It is fully device-local (WebAuthn + localStorage, no server round-trip), so there was no backend flag to flip — this release adds a build-time kill switch and ships it off.

## Change

- New `src/lib/feature-flags.ts` with `BIOMETRIC_LOCK_ENABLED = false` (plain module, importable from server and client components)
- `src/app/(app)/layout.tsx`: pre-paint hide script + `bio-locked` CSS only emitted when the flag is on
- `src/components/BiometricLock.tsx`: disabled path renders children directly and removes any `bio-locked` class a stale cached build's pre-paint script may have set (unbricks a locked device on first fresh load)
- `src/app/(app)/settings/BiometricSection.tsx`: section hidden while disabled, so it can't be re-enrolled

## Re-enable

Set `BIOMETRIC_LOCK_ENABLED = true` and deploy. Enrolled devices keep their localStorage config while the switch is off; their lock resumes automatically.
