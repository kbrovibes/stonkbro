# v0.37.2 — Briefing player: playlist-first, auto-advance, true symmetry

## Playlist-first layout (`BriefingPlayer.tsx`)

The page now reads like a podcast app:

1. Now-playing card (cover art, title, controls)
2. **"Today's moves & details"** — one collapsed expander holding the highlights
   carousel, recommended moves, and the transcript (with its own inner toggle).
   Default is collapsed, so the playlist is immediately visible.
3. **Playlist** — every episode, grouped by day (newest day first), each row
   showing session label, generation hour, duration, and saved state. Rows
   within a day are in generation order — the same order auto-advance uses.
   Tapping a row plays it; tapping the current row toggles play/pause. The
   current row is highlighted with a ❚❚/▶ state glyph.
4. Regenerate button moved to the bottom.

## Auto-advance within the day

`onEnded` now looks up the day's episodes (same `briefing_date`, has audio,
sorted by `created_at`) and plays the next one via a new `playBriefing()`
helper (loads/caches the blob, honors the current speed). After the day's last
episode, playback stops — it never rolls into a previous day.

## Symmetry fixes

- The v0.36.4 three-zone row used `flex-1` flanks, but the left flank held the
  3-pill speed group whose min-content width (~110px) exceeded its share on
  phone widths — flex can't shrink below min-content, so the transport was
  pushed right. The speed control is now a **single cycling chip**
  (1x → 1.25x → 1.5x, `w-12 h-8`) mirrored by the download button at the same
  size, making the flanks genuinely symmetric at any viewport.
- The play glyph's bounding box spanned x 8–20 (center 14 in a 24-unit viewBox)
  plus a `translate-x-0.5` nudge — ~3px right of center at render size. It is
  now a stroke-rounded polygon (`8,6.2 18,12 8,17.8` with `strokeWidth 2`)
  whose optical center (between centroid and bbox center) lands on x=12; the
  CSS nudge is gone.

## Alert banner: quick Clear all (`AlertBanner.tsx`)

The collapsed banner header now carries a **Clear all** pill that acks every
alert in one tap (calls the existing `{ all: true }` endpoint). The header was
restructured from one big `<button>` into a row of sibling buttons
(expand | Clear all | chevron) — no nested-button markup.
