# v0.45.0 — Every bottom-nav destination gets a real glyph

## What broke
Settings → Bottom nav lets you fill its 4 customizable slots from any page in the app. Only the 4 original defaults (Options, Paper, Portfolio, Learn) had a real stroke-icon glyph (`KNOWN_MIDDLE_ICONS` in `BottomNav.tsx`) — everything else picked from the full destination list fell back to rendering its `/more` grid emoji instead. LEAPS Lab was the one reported, but the same gap applied to all 19 other destinations (Bloodbath, Research, Sector Discovery, Explosive Finder, Earnings Calendar, Watchlists, Suggestions, PMCC Picks, PMCC Income, PMCC Scanner, Covered Calls, The Wheel, Trade Signals, Trading Desk, Daily Briefing, Portfolio Manager, Hindsight, Settings).

## Fix
- Added `src/components/nav-icons.tsx`: a single `NAV_ICONS: Record<href, (active) => ReactElement>` map with a dedicated glyph for every entry in `NAV_DESTINATIONS` (`src/lib/nav-destinations.ts`) — 23 total. The 6 that already had a canonical icon somewhere in the codebase (Options, Paper, Portfolio, Learn, Research, Settings) reuse those exact paths; the other 17 are new.
- `src/components/BottomNav.tsx`: reads from `NAV_ICONS` instead of the old 4-entry map. Removed the now-dead duplicate icon definitions (`learnTab`, `portfolioTabs`, the inline Paper/Research SVGs) in favor of the shared map. In development, a destination picked for the nav with no `NAV_ICONS` entry logs a console warning instead of silently degrading to emoji — so a future new page/feature that's added to `MORE_GROUPS` without a glyph is caught immediately rather than shipping emoji-only.

## Files changed
`src/components/nav-icons.tsx` (new), `src/components/BottomNav.tsx`, `CHANGELOG.md`, `package.json`
