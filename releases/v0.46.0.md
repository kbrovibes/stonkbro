# v0.46.0 — Tables are sortable, click any column header

## What changed
Almost every table in the app could not be re-sorted by the viewer — column order was whatever the API/scan returned. Two of Paper Trading Lab's screens weren't even tables: `TradesList` rendered each trade as a description sentence in a stacked list (one day at a time, via date chips), and the Paper home leaderboard ranked bots as card rows keyed off a Today/Total toggle rather than real per-column sort.

## What shipped
New shared primitives (`src/hooks/useSort.ts`, `src/components/table/SortTh.tsx`) provide sort state + a Tailwind sortable `<th>` for any table going forward. Applied to:

- **Paper Trading Lab** (`src/app/(app)/paper/[profileId]/ProfileSections.tsx`, `src/app/(app)/paper/PaperLeaderboard.tsx`):
  - `PositionsTable` sorts on Position/Type/Qty/Avg/Mark/Market value/Unrealized (default: market value, descending — same as the old hardcoded sort).
  - `TradesList` rebuilt as a table: Time / Trade / Reason / Amount, sortable, default chronological.
  - The leaderboard board rebuilt as a table: Bot / Trend / Positions / Equity / Today / Total, sortable, default by Total return descending (same as before). The Today/Total `SegmentedSwitch` now only drives the aggregate header stats, not row order.
- **`src/app/(app)/options/page.tsx`**: CSP/Calls/LEAPS tabs, each sortable on every visible column, defaulting to a synthetic rank (original scan order) so the default view is unchanged.
- **`src/app/(app)/admin/AdminDashboard.tsx`**: token usage table sortable (User/Provider/Feature/Calls/Tokens/Est. $).
- **`src/app/(app)/time-machine/page.tsx`**: the options-legs and stock-sells realized-gains breakdown tables are now sortable; the pre-existing sortable positions table in the same file was left untouched.

## Deliberately out of scope
- `src/app/(app)/plays/refresh/leaps/ScenarioGrid.tsx` — a 2D price-move × time-bucket scenario matrix, not a record table; row/column order is intrinsically meaningful.
- `src/app/(app)/time-machine/detail/page.tsx` — already had a complete bespoke sort implementation.
- Time Machine's "biggest regrets"/"avoided losses" cards — pre-truncated top-N-by-impact lists, not column tables.
- The Options page's "Rationale" text list under each table still iterates the original scan order regardless of table sort — a known minor inconsistency, not fixed here.
